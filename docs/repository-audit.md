# Почему существовало несколько копий

Проверка выполнена 14 сентября 2026 года до изменения исходников.

| Копия | Состояние |
| --- | --- |
| `FootballGroup/` | Локальный Git-репозиторий, 3 коммита, последний `26338f9` от 22 мая 2026 года |
| `FootballGroup-main.zip` | Архив той же версии: все 111 файлов совпадали побайтово, уникальных файлов в ZIP не было |
| `nickihysterics/py-FootballGroupWebsite` | Личный GitHub-репозиторий, 8 коммитов, последний `81f83be` от 2 апреля 2026 года |
| `dev-ITU/FootballGroup` | Старый `origin` локальной папки; адрес на момент проверки недоступен текущей учётной записи |

В локальной папке дополнительно находились три диаграммы и Word-документ, не включённые ни в Git, ни в ZIP. Архив не является другой редакцией исходников. Две Git-истории различались: более поздняя локальная редакция добавила кэширование, обработку недоступного Redis и скриншоты, а также вернула внешние ссылки на медиа, ранее удалённые в личном репозитории.

По содержимому и метаданным это две линии разработки и ZIP-экспорт одной из них. Точная причина создания архива или недоступности старого `origin` из этих данных не следует.

## Как выбрана итоговая версия

- Сохранены локальные улучшения кэширования и структуры приложения.
- За основу демонстрационного наполнения взят личный репозиторий без автоматически загружаемых внешних фотографий.
- Устранены найденные ошибки запуска, импорта и прямых ссылок.
- Итог опубликован в личном репозитории `FootballGroup-WebSite`, с одним корневым коммитом и релизом `v1.0.0`.

Учебные документы вне Git не входят в опубликованный исходный код. По указанию владельца все локальные копии, включая эти документы, удаляются после проверки публикации.
