# Участие

Сохраняйте учебную прозрачность проекта: отличайте архивные данные от актуальных результатов и явно описывайте новые зависимости.

1. Внесите изменение в отдельной ветке.
2. Добавьте регрессионную проверку для исправленного поведения.
3. Запустите проверки из [руководства разработчика](docs/development.md).
4. При изменении React обновите собранный `static/dist`; при изменении интерфейса проверьте RU/EN и мобильную ширину.
5. Опишите проблему, результат и выполненные проверки в pull request.

Не публикуйте `.env`, базы данных, загрузки пользователей или персональные документы. Сообщение коммита: английское действие и комментарий на русском, например `Fix: исправлено открытие профиля игрока`. Релиз 1.0.0 опубликован одним корневым коммитом.
