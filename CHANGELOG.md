# История версий

## 1.0.0 — 2026-09-14

Первый оформленный учебно-демонстрационный релиз FootballGroup.

- Сопоставлены ZIP, локальная версия и личный GitHub-репозиторий.
- Устранён конфликт страницы `/media/` и загруженных файлов: файлы доступны через `/uploads/`.
- Добавлены прямые ссылки на игроков с корректным HTTP 404.
- Импорт выполняется в транзакции; повторный seed сохраняет существующий контент.
- Кэш инвалидируется после commit; локальный запуск работает без Redis.
- Браузерный кэш получил срок жизни и общие запросы без взаимной отмены.
- Архивные данные явно обозначены; демо не подгружает удалённые фотографии.
- Шрифты включены в сборку; улучшены загрузка без JavaScript и reduced motion.
- Обновлены зависимости, настройки Django и Docker; удалён стандартный пароль администратора.
- Добавлены README, архитектура, учебные задания, тесты и CI для трёх ОС.
